- Время ответа `< 1с`

- Статус: `200`
- Время ответа `< 1с`

## TC-AREA-10: Проверка обработки нулевого значения `area_id`

1. Отправить `GET` запрос на `https://api.hh.ru/areas/0`

- Статус: `404` (не существующий регион)

- Не баг в классическом смысле, а недокументированное расширение API
- Требует уточнения у команды HH
