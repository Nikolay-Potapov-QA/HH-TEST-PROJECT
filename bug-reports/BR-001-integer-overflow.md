# BR-001: Integer Overflow на границе INT32_MAX → 502 вместо 400

**Статус:** Bug (подтвержден, воспроизводится стабильно)
**Компонент:** REST API / Areas
**Severity:** Medium
**Приоритет:** Low
**Дата обнаружения:** 03-09-2026

---

## Описание

При запросе `GET /areas/{area_id}` с параметром `area_id`, превышающим INT32_MAX (`2147483647`), API возвращает `502 Bad Gateway` вместо ожидаемого `404 Not Found`.

Это указывает на то, что валидация параметра либо отсутствует, либо нарушается при приведении типов на внутренних слоях обработки запроса.

---

## Шаги воспроизведения

### Граница INT32_MAX

| Значение | Статус | Поведение |
|---|---|---|
| `2147483647` (INT32_MAX) | `404` | Нормальная обработка — регион не найден |
| `2147483648` (INT32_MAX + 1) | `502` | **Ошибка** |
| `9223372036854775807` (INT64_MAX) | `502` | **Ошибка** |
| `9223372036854775808` (INT64_MAX + 1) | `502` | **Ошибка** |

### Точные запросы
GET https://api.hh.ru/areas/2147483648
GET https://api.hh.ru/areas/9223372036854775807
GET https://api.hh.ru/areas/9223372036854775808

---


Все три возвращают одинаковый ответ:

```json
{
    "description": "Bad Gateway",
    "errors": [
        {
            "type": "bad_gateway"
        }
    ],
    "request_id": "..." 
}
```

HTTP статус-код: `502`

---

## Ожидаемое поведение

Согласно документации (`docs/errors.md` в hhru/api), ошибки в параметрах запроса должны возвращать:

- Статус: `404 Not Found`
- Тело: 
```json
{
    "description": "Not Found",
    "errors": [
        {
            "type": "not_found"
        }
    ],
```

---

## Гипотезы

1. **Type Coercion Bug (вероятнее всего)**
   - Где-то в цепочке обработки `area_id` приводится к 32-битному знаковому целому
   - Значение вне диапазона приводит к переполнению/неопределённому поведению


2. **Промежуточный шлюз**
   - Ошибка может быть не на самом сервисе HH, а на уровне Cloudflare/nginx
   - `Server: ddos-guard` в заголовке ответа указывает на presence edge-прокси
   - Однако тело ошибки соответствует формату HH API, не стандартному formata Cloudflare

3. **Недокументированная граница**
   - Возможно, это намеренное ограничение для защиты от DoS
   - Должно быть задокументировано явно

---

## Влияние

- **Severity:** Medium (не блокирует основную функциональность, но нарушает graceful error handling)
- **Сценарий:** Если клиент случайно отправит переполненное число (например, от битой генерации id, или после неправильной обработки большого числа в JavaScript), он получит некрасивую 502 вместо понятной 400
