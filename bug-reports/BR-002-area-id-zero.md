# OBS-001: area_id=0 возвращает 200 вместо 404

**Статус:** Observation (не баг в классическом смысле, требует уточнения)
**Тип:** Undocumented behavior

Запрос `GET /areas/0` возвращает `200 OK` с полным деревом регионов, тогда как остальные невалидные id (`-1`, нечисловые, несуществующие) возвращают `404`.

Возможные причения: type coercion (0 трактуется как "id не передан"), или намеренный virtual root node для tree-компонентов. Не задокументировано.
